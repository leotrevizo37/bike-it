# Code of Conduct

## Purpose

This repository is intended to be a respectful, constructive, and professional space for collaboration.

The goal of this project is to encourage transparency, technical discussion, issue reporting, suggestions, 
and contributions in a way that benefits both the project and its community.

## Expected Behavior

By participating in this repository, you agree to:

- Be respectful in discussions, reviews, and feedback
- Focus on technical and constructive communication
- Assume good intent, especially when discussing code or design decisions
- Report bugs, ideas, and concerns clearly and professionally
- Accept that maintainers may guide, limit, or reject contributions based on the project’s direction

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, insults, or personal attacks
- Discriminatory, hateful, or abusive language
- Trolling, provocation, or intentionally disruptive behavior
- Repeatedly ignoring repository guidelines or maintainer decisions
- Publishing private, sensitive, or confidential information without permission
- Any behavior that creates an unsafe or hostile environment

## Scope

This Code of Conduct applies to:

- Issues
- Pull requests
- Discussions
- Code reviews
- Any other project-related communication spaces managed by the maintainers

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

They may remove, edit, or reject comments, issues, pull requests, or contributions that do not align with these rules.

In more serious or repeated cases, maintainers may restrict or block participation.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainer privately.

For now, reports can be made through a private message or the contact method listed in the repository profile or README.

## Final Note

This is a maintainer-led project. Respectful collaboration is welcome, but the maintainers reserve the right to make 
final decisions regarding repository direction, contribution acceptance, and community standards.
